# 포탈 등록용 이미지 (2026-10-16 배포)

포탈에 그대로 올리는 PNG만 모았습니다. 모듈 폴더마다 분석 개념 그림(`<모듈>_concept.png`)과 주요 결과 그림(`<모듈>_result_<N>.png`)이 있고, 번호는 원고(`docs/Portal_Content.docx`)의 "결과 N"과 같습니다.

- `pipeline/`: 파이프라인 페이지의 분석 흐름(`pipeline.png`)과 분석 개념(`concept.png`)
- 결과 그림이 아직 없는 모듈은 결과를 받은 뒤 채웁니다.

같은 그림의 원본(PDF, TSV, 로그)은 `results/<모듈>/`에 있습니다.
